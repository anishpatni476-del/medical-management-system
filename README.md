# Medical Management System

This is a web-based Medical Store Management System made using Python and Django.

I created this project to manage the daily work of a medical store in a simple and organized way.

## About the Project

The website has two main parts:

### Public Website

Anyone can visit the website without login and see:

- Home page
- About the medical store
- Available medicines
- Services
- Contact information
- Feedback form

Customers can also send a message or submit feedback through the website.

### Owner Panel

The owner can login to the dashboard and manage the medical store.

The owner can:

- Add, update and delete medicines
- Manage medicine categories
- Manage suppliers
- Manage purchases
- Manage stock
- View customer messages
- View customer feedback
- Manage store profile
- Generate reports

Currently, the project uses SQLite as the database.

## Image Storage

ImageKit is used to store and manage uploaded images such as medicine images and store images.

## Reports

The system can generate PDF reports using ReportLab.
